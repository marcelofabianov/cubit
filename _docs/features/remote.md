# Controle remoto e modo área

Números por tier: [`tiers.md`](../tiers.md#autonomia).

## Comandos

Mirando no robô e clicando com o botão direito, dá para:

- ligar e desligar;
- mandar parar e voltar a seguir;
- trocar o modo defensivo;
- ativar ou desativar as funções dos slots exclusivos.

O controle é o mesmo em todos os tiers. As opções bloqueadas aparecem desabilitadas.

## Modo área

A área é marcada com o controle, clicando com o botão direito nos blocos para formar um quadrado ou retângulo.
